# 한글 파일 (.hwp / .hwpx)

한글 프로그램이 없어도 한글 문서를 다룬다. 도구 `scripts/hangul.py` 가 그 일을 한다. 속은 공개 라이브러리 python-hwpx(Apache-2.0)이다.

근거 등급: **[도구 시험]** 공개 시험 파일 93개와 직접 만든 문서로 돌려 본 것(2026-10-24) / **[확인]** 실제 사용자 문서로 해 본 것(날짜를 적는다) / **[추정]** 내 짐작.

---

## 0. 말하는 법

- 쉬운 한국어로 말한다. 물을 것은 선택지로 하나씩 묻고, 추천 하나와 이유 한 줄을 붙인다.
- 도구 이름, 명령어, 영어는 사용자에게 말하지 않는다. "한글 파일 도구로 읽었어요"처럼 말한다.
- 사용자가 질문하면 되묻지 말고 먼저 답한다.
- **글 내용을 바꾸기 전에는 무엇을 어떻게 바꿀지 먼저 보여 주고 묻는다.** (찾아 바꾸기는 바꿀 곳 수를 먼저 말한다.)
- 결과 파일은 전체를 한 번에 준다(SendUserFile). 원본은 건드리지 않고 새 이름으로 저장한다.

---

## 1. 할 수 있는 것과 못 하는 것

**할 수 있는 것** [도구 시험] — 공개 한글 파일 2,798개와 관공서 서식 149개로 대량 시험함(자세한 결과는 references/log.md)
- **읽기**: .hwp(한글 5.0 이후)와 .hwpx의 글, 표, 각주·미주, 글상자 속 글, 링크를 마크다운으로. 시험 파일 93개 중 91개를 읽었다(못 읽은 2개는 배포용 잠금 파일과 아주 큰 파일 — 큰 파일은 글자만 뽑는 예비 방식으로 읽었다).
- **찾아 바꾸기**: 본문·표 안 낱말을 바꾸고, 글자 모양(굵게·색)은 그대로 둔다. 바꾼 부분 말고는 파일 속 부품을 한 바이트도 안 바꾼다(실제 공문 87부품 중 85개 그대로).
- **양식 채우기**: `{{이름}}` 같은 빈칸, 표에서 "성명" 옆 칸, 누름틀(한글의 클릭해서 쓰는 칸)을 채운다.
- **여러 장 만들기**: 명단(**엑셀 .xlsx 바로**, CSV, JSON)으로 한 사람에 한 장씩. 한글 이름 칸(`{{이름}}`)도 된다. 엑셀 날짜는 2026-10-25 모양으로, 27.0 같은 숫자는 27로 들어간다.
- **새 문서 만들기** (폴라리스 뷰어에서 표·글머리표·번호 모두 제대로 보임 [확인: 10-24]): 마크다운 원고 → 제목, 소제목, 문단, 굵게·기울임, 글머리표·번호 목록, 표(머리줄 색), 인용, 가로줄, 쪽 나눔, 가운데·오른쪽 맞춤, **그림**(png·jpg·gif·bmp·webp, 쪽 폭에 맞춰 가운데, 설명 글은 그림 아래 작은 글씨 — 폴라리스 뷰어로 확인 [확인: 10-24]).
- **형식 바꾸기**: hwp → hwpx, hwpx → hwp, 그리고 md·txt·html 로 내보내기. 시험 파일 89개를 hwp로 다시 저장해 글자가 하나도 안 바뀐 것을 확인했다.
- **검사**: 한글이 열기를 거부하는 구조인지 미리 검사한다. 위험하면 **저장 자체를 멈춘다**(깨진 파일을 주지 않는다).
- **미리 보기**: 쪽마다 PNG 그림을 만들어 내가 Read로 직접 본다. **rhwp 엔진(MIT)으로 그려서 한컴 화면과 거의 같다** — 표 선, 글머리표, 서식 칸까지 나온다 [확인: 10-25, 관공서 서식·계획서]. node·크로미움이 없으면 예전 '대충 그리기'로 넘어간다.
- **한글 → PDF**: 같은 rhwp 엔진으로 쪽 크기 그대로 PDF를 만든다. 75쪽 공문(그림 75장)도 됐다 [도구 시험]. PDF 안 글자를 복사하면 굵은 글자가 두 번 붙는 일이 있다(보이는 모양은 정상).
- **두 판 비교**: 고치기 전·후 파일에서 바뀐 문단·지워진 문단·새로 생긴 문단과 바뀐 글자를 알려 준다(표 안 글 포함).
- **개인정보 가리기**: 주민등록번호(뒤 6자리), 휴대·일반 전화(가운데), 이메일, 계좌번호처럼 보이는 숫자, 지정한 이름을 ●로 가린다. 날짜(2026-10-25)는 건드리지 않는다. 빈 관공서 서식 149개에서 잘못 잡은 것 0개 [도구 시험].

**못 하는 것**
- 작업 공간 안에서 한글 프로그램으로 열어 보는 것 — 구조 검사만 한다. 만드는 기능을 바꿨으면 사용자 PC의 무료 한컴오피스 뷰어로 열어 확인한다(2026-10-25 한컴 뷰어로 6개 문서 확인 완료 [확인: 10-25]). 폴라리스 같은 다른 뷰어는 문단 모양 문제를 못 보여 줄 수 있다.
- 암호 걸린 파일, 배포용(읽기 전용) 파일 — 원본이 필요하다고 말한다.
- 일부 .hwp의 특수 필드가 든 문서 저장 — 도구가 저장을 멈추고 이유를 알려 준다. 이때는 사용자에게 **한글에서 "다른 이름으로 저장 → HWPX"로 바꾼 파일**을 부탁한다.
- 미리 보기·PDF는 한컴과 '거의' 같다. 글꼴이 작업 공간에 없으면 비슷한 글꼴로 그려 줄바꿈 위치가 조금 다를 수 있다. 정확한 확인은 사용자 PC의 무료 한컴오피스 뷰어로 한다.
- 개인정보 가리기는 그림 속 글자와 문서 정보(작성자 등)는 못 가린다.
- 글꼴·쪽 넘김 위치를 한글과 똑같이 맞추는 것.

## 2. 일하는 순서

1. **준비** (채팅마다 한 번)
   ```
   pip install -q --break-system-packages python-hwpx olefile openpyxl pillow
   H=$(find / -name hangul.py -path '*hangul-file*' 2>/dev/null | head -1); echo $H
   ```
   미리 보기·PDF는 node 와 playwright(크로미움)를 쓴다. rhwp 엔진(@rhwp/core)은 처음 쓸 때 npm으로 알아서 받는다(약 10MB, `~/.cache/hangul-file`).

2. **파일 받기**: 채팅에 올린 파일, 또는 연결된 PC 폴더의 파일. **원본은 작업 폴더에 복사해서** 쓴다.

3. **먼저 본다** — 무엇이든 하기 전에:
   ```
   python3 $H info 문서.hwp        # 문단·표·그림·누름틀·{{빈칸}} 수
   python3 $H read 문서.hwp --out 문서.md   # 글 전체
   ```
   `read` 결과를 직접 읽고 문서가 어떤 것인지 한두 줄로 말한다.

4. **할 일에 맞는 명령**

   | 사용자 말 | 명령 |
   |---|---|
   | "이거 읽어 줘 / 요약해 줘" | `read` 후 내가 요약 |
   | "홍길동을 김철수로 다 바꿔 줘" | `replace 문서.hwpx 홍길동 김철수 --out 문서_고침.hwpx` (짝을 여러 개 이어 쓸 수 있다, 많으면 `--map 바꿀말.json`) |
   | "이 신청서 채워 줘" | 값을 `값.json`에 적고 `fill 양식.hwp 값.json --out 채운.hwp` (원래 형식 그대로) |
   | "명단대로 한 장씩" | `merge 양식.hwpx 명단.xlsx --out 폴더 --name '{index:02d}_{이름}.hwpx'` (엑셀은 첫 시트, 첫 줄이 칸 이름. CSV·JSON도 됨) |
   | "한글 파일로 만들어 줘" | 원고를 마크다운으로 쓰고 `new 원고.md --out 문서.hwpx` |
   | "hwp로 줘 / hwpx로 바꿔 줘" | `convert 문서.hwpx 문서.hwp` |
   | "이거 한글에서 열려?" | `check 문서.hwpx` |
   | "PDF로 줘" | `pdf 문서.hwp --out 문서.pdf` |
   | "뭐가 바뀌었어? / 두 개 비교해" | `diff 앞판.hwp 새판.hwp` |
   | "개인정보 가려 줘 / 주민번호 가려" | 먼저 `redact 문서.hwp --dry`로 가릴 곳을 보여 주고 묻는다 → `redact 문서.hwp --words 홍길동 --out 문서_가림.hwp` |

   **값.json 쓰는 법** (fill)
   ```json
   {
     "이름": "김철수",                 ← 문서의 {{이름}} 빈칸, 같은 이름의 누름틀, 같은 이름의 셀 필드를 채운다
     "성명 >": "김철수",               ← 표의 '성명' 칸 옆을 알아서 찾는다 (오른쪽 빈칸 → 아래 빈칸 → 없으면 '성명' 칸 안 이름표 뒤)
     "상속인/성명 >": "김상속",        ← '상속인' 묶음 안의 '성명' (같은 이름표가 여러 개일 때)
     "성명#2 >": "이영희",             ← 두 번째 '성명' 칸
     "주소 > down": "경기도 ...",      ← 방향을 직접 정할 때 (right/left/up/down, 여러 번: "합계 > right > right")
   }
   ```
   - **실제 관공서 양식 149개로 맞춘 방식** [확인: 10-25]: 이름표 칸 옆을 알아서 찾는 `"이름표 >"`를 먼저 쓴다. 105개 양식 중 101개가 한 번(또는 아래 고르기 한 번)에 채워졌다.
   - 결과의 "못 채운 곳"에 **"같은 이름표가 ○개 있음 → 이렇게 골라 주세요: 상속인/성명, ..."**이 나오면 그 이름 그대로 다시 넣어 채운다. 묶음 이름까지 같으면 `성명#1(변경 전)`처럼 번호로 알려 준다 → `성명#1 >`로 쓴다.
   - "성명(한자)", "성명<br>(대표자)"처럼 괄호가 붙은 칸도 `"성명 >"`으로 찾는다.
   - 관공서 양식은 넓은 칸 위쪽에 이름표가 있고 그 칸 안에 적는 모양이 많다. 이때는 이름표 뒤에 이어 쓴다("주소  경기도 …"). 한컴 뷰어로 확인했다.
   - 양식을 채우기 전에 `read`로 표를 보고 어떤 칸을 채울지 사용자에게 먼저 보여 준다.

   **새 문서 원고 쓰는 법** (new)
   - `#` 문서 제목(크고 가운데), `##` 큰 제목, `###` 작은 제목
   - `**굵게**`, `*기울임*`, `- 글머리표`(두 칸 들여 쓰면 2단계), `1. 번호`
   - `| 표 |` (첫 줄이 머리줄, 색이 깔린다), `> 인용`, `---` 가로줄, `<쪽나눔>`
   - `<가운데> 글`, `<오른쪽> 글` — 날짜·서명 줄에 쓴다
   - `![그림 설명](그림.png)` — 그림. 경로는 원고 파일 기준. 폭을 정하려면 뒤에 `{폭=80mm}` 또는 `{폭=50%}`. 안 정하면 원래 크기(쪽 폭보다 크면 쪽 폭). 설명을 비우면(`![](그림.png)`) 설명 줄 없이 그림만

5. **저장 형식**: 사용자가 준 형식 그대로 돌려준다(.hwp → .hwp). 사용자가 형식을 말하지 않은 새 문서는 **.hwpx**(한글 2014 이후에서 열림)로 만든다. 옛 한글을 쓴다고 하면 .hwp로 만든다.

6. **확인** — 주기 전에 꼭:
   ```
   python3 $H check 결과.hwpx
   python3 $H read 결과.hwpx          # 바뀐 글이 맞나
   python3 $H preview 결과.hwpx --out 미리보기 --pages 3
   ```
   미리 보기 PNG를 Read로 보고 글이 빠지거나 밀리지 않았는지 본다. 결과 JSON의 "못 채운 곳", "아직 남은 빈칸", "주의"가 비어 있지 않으면 사용자에게 말한다.

7. **알려 주기**: 무엇을 몇 곳 바꿨는지 한두 줄, 파일 전달(SendUserFile), 미리 보기 그림 한 장. "한글에서 열어 보고 이상하면 알려 주세요"를 붙인다.

8. 작업을 마치면 실제로 해 보고 알게 된 것(헛짚은 것, 안 된 것, 사용자가 한글로 열어 본 결과)을 `references/log.md`에 적는다.

## 3. 자주 나오는 문제

| 증상 | 뜻 | 할 일 |
|---|---|---|
| "배포용(읽기 전용)" | 본문이 잠긴 파일 | 원본(배포용으로 바꾸기 전 파일)을 부탁한다 |
| "한글 97 이전(한글 3.0)" | 1997년 이전 아주 옛날 형식 | 한글이나 무료 한컴오피스 뷰어에서 열어 HWP/HWPX로 다시 저장한 파일을 부탁한다 |
| "깨진 특수 글자가 있어 서식째로는 고칠 수 없습니다" | 문서 속 글자가 깨짐 | `read`로 글자만 읽어 준다. 고치려면 한글에서 다시 저장한 파일을 부탁한다 |
| ".hwp 형식으로 아직 옮길 수 없는 부분" | .hwp로 저장할 수 없는 개체가 있음 | `--out`을 .hwpx로 바꿔 저장한다 |
| "암호가 걸린" | 문서 암호 | 사용자가 한글에서 암호를 풀고 다시 저장한 파일이 필요하다 |
| "저장 안 함" | 그대로 저장하면 한글이 안 열 위험 | 원본은 무사하다. .hwp면 "다른 이름으로 저장 → HWPX"로 바꾼 파일을 부탁한다 |
| 찾아 바꾸기 "바꾼 곳: 0" | 낱말이 없거나, 띄어쓰기·특수 빈칸이 다름 | `read`로 실제 글자를 보고 그대로 복사해 다시 |
| 여러 장 만들기에서 "남은 빈칸" | 명단 칸 이름과 `{{ }}` 이름이 다름 | 명단 첫 줄 이름을 문서 빈칸 이름과 똑같이 |
| "계산식 칸 ○○의 값이 비어 있습니다" | 엑셀에서 한 번도 안 열고 저장된 파일(계산 결과가 저장 안 됨) | 엑셀에서 열고 저장한 파일을 달라고 하거나, 그 칸 값을 직접 받는다 |
| "옛 엑셀(.xls)은 못 읽습니다" | 2003년 이전 엑셀 형식 | 엑셀에서 .xlsx로 다시 저장해 달라고 한다 |
| "그림 파일이 없습니다" | 원고의 그림 경로가 틀림 | 그 자리에 [그림 없음] 글이 들어간다. 경로를 고쳐 다시 만든다 |
| 명단 글자가 깨짐 | 엑셀 CSV 글자 방식 | 도구가 UTF-8과 CP949를 둘 다 읽는다. 그래도 깨지면 엑셀에서 "CSV UTF-8"로 저장 |
| 미리 보기에 ●·표 선이 없음 | 미리 보기의 한계 | 파일에는 있다. 걱정되면 사용자에게 한글로 열어 봐 달라고 한다 |
